# Network Security System (Phishing Detection)

A comprehensive Machine Learning project designed to detect phishing websites. This system utilizes a modular data pipeline to ingest, validate, transform, and model network data, providing accurate predictions on potential security threats.

## 🚀 Key Features

* **Modular Pipeline:** Organized into distinct components for Data Ingestion, Data Validation, Data Transformation, and Model Training.
* **Machine Learning:** Utilizes Scikit-Learn for training classification models to identify phishing patterns.
* **MongoDB Integration:** Efficient storage and retrieval of training and testing data.
* **FastAPI Backend:** A robust API to handle prediction requests and file uploads.
* **Interactive UI:** Simple Jinja2-based web interface to upload CSV files and view prediction results in a table format.
* **Data Validation:** Implements rigorous schema validation to ensure data quality before processing.

## 🛠️ Tech Stack

* **Programming Language:** Python 3.10+
* **Framework:** FastAPI
* **Database:** MongoDB
* **Machine Learning:** Scikit-Learn, Pandas, NumPy
* **Containerization:** Docker
* **Templating:** Jinja2
